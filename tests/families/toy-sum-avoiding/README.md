# Toy family: numbers with no pair adding up to a total

For the kit's tests only; never published.

The object is `{"numbers": [a, b, ...]}`: distinct whole numbers from 1 to `limit`, no two of them adding
up to `total`. The params are `{"limit": L, "total": T}`. No other keys. The score is how many numbers.

A pass shows that this one list passes the toy checker for those params, and nothing else.
